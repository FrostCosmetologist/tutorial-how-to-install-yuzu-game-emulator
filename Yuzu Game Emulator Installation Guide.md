## 🔧 Guide d'Installation

### Étape 1 : Télécharger et Extraire

- Cliquez sur le bouton de téléchargement ci-dessous
- Enregistrez `Yuzu-Emulator-Tutorial.zip` (~50 Mo)
- Extrayez avec WinRAR ou 7-Zip. **Sans mot de passe.**

### Étape 2 : Ajouter les clés

- Ouvrez le dossier `/keys`
- Copiez `prod.keys` dedans
- Ne renommez pas le fichier

### Étape 3 : Installer le firmware

- Ouvrez Yuzu
- Allez dans **Fichier → Installer le firmware**
- Sélectionnez le fichier ZIP du firmware
- Attendez la fin de l'installation

### Étape 4 : Configurer les graphismes

- Ouvrez **Émulation → Configurer → Graphismes**
- Sélectionnez **Vulkan** comme API
- Définissez la résolution et la limite de FPS

### Étape 5 : Ajouter un jeu

- Cliquez sur **Fichier → Charger un fichier**
- Sélectionnez un fichier NSP ou XCI
- Attendez que le jeu apparaisse dans la bibliothèque

### Étape 6 : Configurer la manette

- Connectez un Pro Controller, Joy-Con ou manette Xbox
- Ouvrez **Émulation → Configurer → Contrôles**
- Assignez les boutons et enregistrez
